ALPHA AI — V4 TWO-TIER HEADER
=============================

ปรับส่วนหัวให้เป็นโครง 2 ชั้นแบบเว็บไซต์ตัวอย่าง

Desktop
-------
1) Brand Header
   - Alpha AI
   - DARA ACADEMY
   - จัดกึ่งกลาง

2) Navigation Bar
   - หน้าแรก
   - เกี่ยวกับ Alpha
   - ความสามารถ
   - สำหรับใคร
   - คู่มือ
   - Responsible AI
   - FAQ
   - เริ่มใช้งาน

3) Hero
   - อยู่ต่อจาก Navigation ทันที
   - ใช้ <img> จริง width:100%; height:auto;
   - ไม่ crop / ไม่ zoom / ไม่ overflow

Mobile
------
1) Brand / Logo อยู่ด้านบน
2) แถบเมนูด้านล่าง:
   หน้าแรก          ☰
3) กด ☰ เพื่อเปิดเมนูแนวตั้ง
4) Hero รักษาสัดส่วนภาพต้นฉบับครบ

หมายเหตุ
--------
- ไม่มี box-shadow
- ไม่มี gradient
- ใช้โครงสีเรียบตาม wireframe เดิม
- Logo ตอนนี้เป็นข้อความ placeholder สามารถเปลี่ยนเป็นไฟล์ logo จริงได้ภายหลัง
