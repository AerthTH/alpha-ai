ALPHA AI — REFINED UI
=====================

เวอร์ชันนี้คงโครงสร้างเว็บเดิมทั้งหมด และปรับความเนียนของงานภาพเป็นหลัก

สิ่งที่ปรับ
-----------
- เปลี่ยนฟอนต์เป็น IBM Plex Sans Thai + Inter (Google Fonts)
- จัดระบบ typography และ spacing ใหม่ให้สม่ำเสมอ
- ปรับ Header / Navigation ให้เบาและทันสมัยขึ้น
- ปรับ CTA และสถานะ hover/focus
- ปรับ Hero ให้ยังคงสัดส่วนภาพเดิม ไม่ crop
- คง Apple-inspired Showcase / Parallax เดิม
- ปรับ Card, FAQ, Placeholder และ Footer ให้ดูสะอาดขึ้น
- ปรับ responsive สำหรับ Tablet / Mobile ให้สมดุลขึ้น
- แก้ลิงก์เมนู “เกี่ยวกับ Alpha” ให้เลื่อนไปยัง Intro section ได้ถูกต้อง
- รวม CSS เดิมที่ซ้ำ/ชนกันให้เหลือระบบเดียว

หมายเหตุ
--------
Google Fonts ต้องเชื่อมต่ออินเทอร์เน็ตตอนเปิดเว็บ หากโหลดไม่ได้ ระบบจะ fallback ไปยังฟอนต์ของเครื่องโดยอัตโนมัติ
